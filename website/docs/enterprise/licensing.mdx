# Licensing and editions

The NexusFlow community edition is available under Apache-2.0 and includes the open-source data infrastructure and connectors published in the main repository.

Enterprise capabilities and separately distributed connectors may use commercial licensing. Read the current edition boundary in [`LICENSING.md`](https://github.com/ailake-io/nexusflow/blob/main/LICENSING.md) and [`docs/ENTERPRISE_LICENSING.md`](https://github.com/ailake-io/nexusflow/blob/main/docs/ENTERPRISE_LICENSING.md).
