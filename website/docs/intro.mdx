# NexusFlow

NexusFlow is an open-source Rust platform for moving, transforming, vectorizing, and orchestrating data through batch and streaming pipelines.

It combines a visual node-based interface with a single backend that exposes the API, WebSocket progress, UI, checkpoints, authentication, and observability.

## What you can do

- Connect databases, warehouses, files, APIs, queues, and vector stores.
- Build pipelines with reusable sources, transformations, and sinks.
- Use SQL or no-code transformations for filtering, joins, casts, and enrichment.
- Add CDC, embeddings, RAG, scheduling, alerts, RBAC, and operational checkpoints.
- Run locally with Docker, use published installers, or build from source.
